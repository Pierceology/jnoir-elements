# jnoir-elements

Custom elements for jnoirbranding.com, served from GitHub Pages.

Point a Wix custom element's source URL at a file here and a `git push` is live
in under a minute. No editor, no Publish.

Base: https://pierceology.github.io/jnoir-elements/

After changing an element's source URL in the Wix editor, check the tag name.
Wix silently resets it to `wix-default-custom-element`, and the element renders
black if the file does not also define that tag.
